### Amazon RDS (Relational Database Service)
#### 工作原理

>[!obsidian] Amazon RDS 是一个托管式服务的集合，可以简化在云中设置、运营和扩展数据库的过程

提供八种热门引擎以供选择：
- [Amazon Aurora PostgreSQL 兼容版](https://aws.amazon.com/rds/aurora/?pg=ln&sec=hiw)
- [Amazon Aurora MySQL 兼容版](https://aws.amazon.com/rds/aurora/?pg=ln&sec=hiw)
- [RDS for PostgreSQL](https://aws.amazon.com/rds/postgresql/?pg=ln&sec=hiw)
- [RDS for MySQL](https://aws.amazon.com/rds/mysql/?pg=ln&sec=hiw)
- [RDS for MariaDB](https://aws.amazon.com/rds/mariadb/?pg=ln&sec=hiw)
- [RDS for SQL Server](https://aws.amazon.com/rds/sqlserver/?pg=ln&sec=hiw)
- [RDS for Oracle](https://aws.amazon.com/rds/oracle/?pg=ln&sec=hiw)
- [RDS for Db2](https://aws.amazon.com/rds/db2/?pg=ln&sec=hiw)
