## 概述

面向对象**设计**的基本任务是把[[面向对象的分析（OOA，Object Oriented Analysis）]]模型转换为[[面向对象的设计（OOD，Object Oriented Design）]]模型

### 面向对象的分析模型

主要由**顶层架构图**、**用例与用例图**、**领域概念模型**构成

### 设计模型的组成

- 以`包图`表示的`软件体系结构图`

- 以`交互图`表示的`用例实现图`

- 完整精确的`类图`

- 针对复杂对象的`状态图`

- 描述流程化处理过程的`活动图`
